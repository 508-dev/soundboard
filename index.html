508.dev Soundboard

An F-Droid repository with signed release builds of 508.dev Soundboard.

Add this repository

In the F-Droid app: Settings → Repositories → +, then paste:

https://508-dev.github.io/soundboard/fdroid/repo?fingerprint=d98c77e95f22bc3947fe86a705807720852cbacc8a40fa1c8c4d0814a7776267

Repository URL: https://508-dev.github.io/soundboard/fdroid/repo
Signing fingerprint (SHA-256): d98c77e95f22bc3947fe86a705807720852cbacc8a40fa1c8c4d0814a7776267

These builds are signed with the same key as the APKs attached to the project's GitHub Releases, so you can switch between the two without uninstalling. Builds from f-droid.org are signed by F-Droid instead and are not interchangeable with these.
