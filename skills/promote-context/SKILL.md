# Promote Context

Use when durable `.context/` learnings from a worktree should be promoted to the canonical repo.

## Workflow

1. Finish the user's task first.
2. Identify concise durable learnings: confirmed fixes, recurring failure patterns, decisions, runbooks, or architecture constraints.
3. Find the canonical repo root when in a linked worktree.
4. Merge into an existing topic file when possible.
5. Avoid raw logs, transcripts, screenshots, secrets, or speculative notes.
6. Clearly distinguish confirmed facts from inference.

Promotion is useful but should not block shipping the user's requested change.
